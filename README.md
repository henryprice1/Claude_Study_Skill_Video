# Claude Study Skill: Video

A Claude skill that turns your study material (textbook pages, notes, outlines) into a narrated video lesson web page. It has chapters, animated maps and charts, on-screen captions, fun facts, quick learning checks, and a narrator picker.

## What's here

- `study-video/SKILL.md`: the skill itself. It's the only file you need.

## Install

1. Download this repo (green **Code** button → **Download ZIP**) and unzip it.
2. Zip just the `study-video` folder, so `SKILL.md` sits inside it.
3. In Claude, open Settings, find **Skills**, and upload that zip.

## How to use

1. Start a chat with Claude and attach your material (photos of pages, PDFs, or notes).
2. Ask: *"Make a study video for this."*
3. Claude builds the lesson and publishes it as a web page.
4. Press ▶ to watch. Answer the guess-first question before each chapter and the quick quiz after it. Use the CC, speed, full-screen, and narrator buttons as you like.

After you watch, practice with the study-train skill to lock it in.
